# Fleet Desk

Отдельное настольное приложение для управления автопарком Majestic RP.

## Возможности

- гараж с фотографиями транспорта;
- встроенный каталог из 956 позиций Fletcher Wiki;
- отдельные профили персонажей со своими балансами и статистикой;
- статусы: свободна, в аренде, на продаже, личная;
- почасовая и посуточная аренда с таймером и историей;
- сохранённые шаблоны объявлений с копированием одной кнопкой;
- покупки, продажи, доходы и расходы;
- кроп, уменьшение и сжатие тяжёлых игровых скриншотов с сохранением в выбранную папку;
- расчёт стоимости автопарка и финансовой статистики;
- локальное хранение данных;
- экспорт и импорт резервной копии JSON.

## Запуск на Windows

### Готовая portable-версия

Запустите `Fleet Desk 1.1.2.exe`. Установка, Node.js и командная строка не нужны.

При первом запуске Windows может показать SmartScreen, потому что сборка не подписана коммерческим сертификатом.

### Запуск из исходников

1. Установите Node.js LTS с сайта nodejs.org.
2. Откройте CMD в папке приложения.
3. Выполните `npm install`.
4. Выполните `npm start`.

## Сборка EXE

В CMD выполните `npm run pack:win`. Установщик `Fleet Desk Setup` появится в папке `release`. После первой установки приложение проверяет обновления при запуске и загружает новые версии автоматически.

## Выпуск новой версии

Обновите поле `version` в `package.json`, создайте коммит и тег вида `v1.1.3`, затем отправьте тег на GitHub. GitHub Actions соберёт установщик и опубликует Release с файлами автообновления.
